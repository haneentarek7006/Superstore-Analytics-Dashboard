## 📈 Dashboard Features & Page Breakdown

### 📊 1. Overview Page
- Decomposition Tree Analysis: Interactive breakdown showing total sales flows from Region (West: $725.4K, East: $678.7K, Central: $501.2K, South: $391.7K) down to individual Product Categories (Furniture, Technology, Office Supplies).
- Sales by Category: Donut chart highlighting category contributions (Technology: 36.4%, Office Supplies: 31.3%, Furniture: 32.3%).
- Gauge Charts: Instant visual indicators tracking Profit Margin (12.47%), Total Profit ($286.4K), and Total Discount (1.56K).

### 🔍 2. Analyze Page
- Geographic Analysis: Interactive map displaying sales across major US cities (New York City: $0.26M, Los Angeles: $0.18M, Seattle: $0.12M).
- Top Product Performance: Horizontal bar chart displaying Total Sales by Segment/Product (e.g., *Canon imageCLASS 2200*, *Fellowes PB500 Electric Punch*).
- Profitability Breakdown: Total Profit by Sub-Category ranking high-margin products like *Copiers*, *Phones*, *Accessories*, and *Paper*.
- Shipping Logistics: Total Sales by Ship Mode analyzing revenue generated through *Standard Class*, *Second Class* ($0.46M), *First Class* ($0.35M), and *Same Day* ($0.13M).

### 📋 3. Table View Page
- Granular Order Records: Comprehensive data table listing individual transactions with key fields including Order ID, Order Date, City, Customer Name, Category, Sub-Category, Ship Mode, and Total Quantity.

---

## 🛠️ Tools & Techniques Used
- Business Intelligence: Microsoft Power BI
- Data Transformation: Power Query (ETL)
- Advanced DAX Measures: Custom KPIs, Profit Margins, and Aggregations
- UI/UX Design: Custom Dark Neon UI with smooth page navigation buttons (Overview, Analyze, Table) and dynamic top slicers (State, Sub-Category, Year, Month).
